# Simulador Orbital — Leyes de Kepler

Simulador web del movimiento orbital bajo gravitación universal, con
verificación de conservación de energía y de las tres leyes de Kepler.

- Métodos numéricos: Euler-Cromer y velocity-Verlet.
- Escenarios: Tierra–Luna, Sol–Tierra y sistema solar interno.
- Edición de cuerpos, tipos de órbita y análisis de las tres leyes.

El código y la documentación están en
`https://github.com/edimez14/orbital-simulator`.
